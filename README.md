# 🏦 Bharat Bank Management System

A Python + MySQL based **console banking system** that simulates real-world banking operations like account management, deposits, withdrawals, and transaction tracking.

---

## 🚀 Features

- Create bank accounts with personal details
- Deposit money securely
- Withdraw money with balance validation
- View account details
- Track all transactions (Deposit / Withdrawal)
- Mini backend-style architecture using Python + MySQL

---

## 🛠 Tech Stack

- Python 3
- MySQL
- PyMySQL
- CLI (Command Line Interface)
